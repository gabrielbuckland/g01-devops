== VM Setup

=== 1. Debian aktualisieren

[source,bash]
----
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl ca-certificates gnupg lsb-release
----

=== 2. Curl, Git etc installieren

[source,bash]
----
sudo install -m 0755 -d /etc/apt/keyrings
----

=== 3. Docker engine installieren

[source,bash]
----
curl -fsSL https://download.docker.com/linux/debian/gpg | \
sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

echo \
"deb [arch=$(dpkg --print-architecture) \
signed-by=/etc/apt/keyrings/docker.gpg] \
https://download.docker.com/linux/debian \
$(lsb_release -cs) stable" | \
sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker

docker --version
docker compose version
----

add user to docker group
[source,bash]
----

sudo usermod -aG docker $USER
newgrp docker
----

=== Gitlab-Runner einrichten auf dem Gitlab-UI

. Geh zu https://gitlab.switch.ch/hslu/edu/bachelor-computer-science/devops/25hs01/g01/g01-form/-/settings/ci_cd[GitLab CI/CD Einstellungen]
. Öffne das *Runner* Menü → *Create project runner*
. Erstelle einen tag, e.g. `test-env-runner`
. Schränke den Runner auf das Projekt ein
. Erstelle den Runner
. Wähle *Linux* als das OS
. Kopiere den token in das Clipboard

=== Runner aufsetzen

[source,bash]
----
sudo curl -L --output /usr/local/bin/gitlab-runner \
https://gitlab-runner-downloads.s3.amazonaws.com/latest/binaries/gitlab-runner-linux-amd64
----
[source,bash]
----
sudo chmod +x /usr/local/bin/gitlab-runner
----
[source,bash]
----
sudo useradd --comment 'GitLab Runner' --create-home gitlab-runner --shell /bin/bash
----
[source,bash]
----
sudo gitlab-runner install --user=gitlab-runner --working-directory=/home/gitlab-runner
sudo systemctl enable --now gitlab-runner

sudo gitlab-runner register \
  --url "https://gitlab.switch.ch/" \
  --registration-token "<PROJECT_TOKEN>" \
  --executor "docker" \
  --docker-image "docker:28.4.0-cli" \
  --docker-privileged
----

Als nächstes füge folgendes in der Runner-Config hinzu `/etc/gitlab-runner/config.toml`:

[source,toml]
----
# at top if missing:
concurrent = 2
request_concurrency = 2

[[runners]]
  executor = "docker"
  [runners.docker]
    pull_policy = "if-not-present"
    volumes = ["/var/run/docker.sock:/var/run/docker.sock", "/cache"]
----

Nach der Konfig-Änderung muss der gitlab-runner neugestartet werden.

[source,bash]
----
sudo systemctl restart gitlab-runner
sudo gitlab-runner list
sudo systemctl status gitlab-runner --no-pager
----
